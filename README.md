## 🎨 Design Specifications

### Original Theme: Reland (Real Estate WordPress Theme)

### Color Palette
| Variable | Hex | Usage |
|----------|-----|-------|
| **Primary (Brand)** | #C41E3A | Logo, buttons, accents (burgundy red) |
| **Secondary** | #202020 | Headings, dark text |
| **Background Light** | #FFFFFF | Main background |
| **Background Cream** | #F9FAF1 | Alternate sections |
| **Text Body** | #797978 | Body text |
| **Text Muted** | #9B9B9B | Secondary text |
| **Accent Gold** | #BD9A68 | Luxury accents (optional) |

### Typography
| Usage | Font Family | Weight |
|-------|-------------|--------|
| Body | Montserrat | 400, 500, 600 |
| Headings | Vidaloka (serif) | 400 |
| Alternative | Playfair Display | 400, 700 |

### Design Features
- Clean, elegant real estate design
- Light background with dark accents
- Large hero images with overlays
- Card-based gallery layouts
- Smooth scroll animations
- Mobile-first responsive design
- Curved visual elements (matching building design)

## 📄 Page Structure

### Homepage (index.html)
1. **Navbar** - Fixed, transparent → solid on scroll
   - Logo (left)
   - Navigation: Ana Sayfa, Galeri, İletişim
   - Language switcher (TR/EN)
2. **Hero Section** - Full-screen with hero-building.jpg
   - Title: "Denize 50 Metre Mesafede Lüks Yaşam"
   - Subtitle: Property tagline
   - CTA Button: "Galeriyi İncele" / "İletişime Geç"
3. **Features Section** - Icon cards
   - 50m to Sea, Pool, Modern Design, Luxury Interiors
4. **Gallery Preview** - 6 images grid with lightbox
5. **Video Section** - Promo video with play button overlay
6. **About Section** - Brief intro with building render
7. **Location Section** - Aerial view image or map
8. **Contact CTA** - Call to action with WhatsApp button
9. **Footer** - Contact info, social links, copyright

### Gallery Page (galeri.html / gallery.html)
1. **Hero Banner** - "Galeri" / "Gallery"
2. **Filter Buttons** - Tümü / İç Mekan / Dış Mekan / Konum
3. **Image Grid** - Masonry layout (24 images)
4. **Lightbox** - Full-screen image viewer

### Contact Page (iletisim.html / contact.html)
1. **Hero Banner** - "İletişim" / "Contact"
2. **Contact Info Cards** - Address, Phone, Email, WhatsApp
3. **Contact Form** - Name, Email, Phone, Message
4. **Map** - Google Maps embed or location image
